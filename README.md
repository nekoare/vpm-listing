# Nekoare VPM Packages

VCC / ALCOM 用のパッケージリポジトリです。

## パッケージを追加する

以下のURLをVCC / ALCOMに追加してください：

```
https://nekoare.github.io/vpm-listing/index.json
```

## 収録パッケージ

| パッケージ | 説明 |
|---|---|
| com.nekoare.chimera-hair-master | キメラヘアマスター |
| com.nekoare.mask-creation-tool | マスク作成支援ツール |

## リスティングの更新

パッケージの新バージョンをリリースした後、このリポジトリの Actions タブから「Build VPM Listing」を手動実行してください。
